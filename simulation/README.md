# Simulation (仿真主线)

当前仓库的**主要研发工作面**在 `simulation/`。

- `simulation/`：算法验证、语义地图、协同重规划、可视化输出
- `src/`：真实设备控制代码，不作为当前仿真主线修改目标
- `tests/`：真实飞控/硬件诊断脚本，不参与当前仿真协同逻辑

## 当前机制

本目录实现的是一个**事件驱动的地空协同仿真**：

1. 无人机先基于全局但有误差的透视地图规划初始路径 `P_0`
2. 机器狗沿路径前进
3. 当机器狗的视域圆与未知特殊地形**相切**时立即暂停
4. 机器狗上传该障碍物的**真实几何形状 + 语义标签**
5. 无人机修正内部融合地图并重新规划 `P_1 / P_2 / ...`
6. 机器狗继续沿最新路径前进，直到到达目标

补充约束：

- 路径规划输出会做一次**直线可视化简**：只要两点之间直线段可行，就直接保留线段，不再保留网格 A* 带来的细小折线抖动
- 每次事件只上传**本次相切触发的那个特殊障碍物**的完整几何与语义，不会把视域外障碍物，也不会把同一时刻未触发的其他障碍物一起融合进 UAV 地图

## 三张地图

### 1. 真实物理地图
- 保存所有真实障碍物和地形细节
- 包含可钻行矮墙、沼泽/流沙/水面、死胡同等

### 2. 机器狗语义地图
- 只对视域圆内的内容有真值认知
- 能区分可钻行矮墙和不可通行地面

### 3. 无人机透视地图
- 全局可见，但语义有缺陷
- 矮墙被看成实心障碍
- 沼泽/流沙/水面被看成普通地面

## 关键文件

| 文件 | 作用 |
| --- | --- |
| `main_path_fusion.py` | 主仿真入口：相切触发、上传、融合重规划 |
| `semantic_maps.py` | 三张地图转换、语义上传包、触发点检测 |
| `map_generator.py` | 2D/3D 障碍物模型，支持多边形与距离计算 |
| `algorithm/a_star.py` | 通用 2D A* 规划器 |
| `visualization/comparison.py` | 独立场景可视化工具 |
| `config/scenarios/*.json` | 仿真场景配置 |

## 运行方式

```bash
# 批量跑三组场景
python3 simulation/main_path_fusion.py

# 单独看某个场景地图
python3 simulation/visualization/comparison.py \
  --config simulation/config/scenarios/scenario_a_simple.json \
  --output /tmp/scenario_a_map.png
```

## 输出文件

每个场景会在 `simulation/output/<scenario_id>/` 下生成：

- `*_fusion.png`：真实地图 / 无人机透视图 / 机器狗语义图 / 融合地图
- `*_metrics.png`：重规划次数、路径长度、语义修正统计
- `*_report.txt`：事件日志、上传语义包、最终结果摘要
